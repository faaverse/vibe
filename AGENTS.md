# Project Instructions

## Workflow
- Read the existing code before changing it.
- Make the smallest reasonable change.
- Run the relevant tests or checks after editing.
- Do not modify secrets, .env files, SSH keys, or system configuration.
- Do not force-push or rewrite Git history.
- Do not commit secrets, credentials, API keys, or tokens.
- Prefer a feature branch or isolated worktree for non-trivial changes.
- Commit only when the requested change is working and verified.
- Never push to main unless explicitly instructed by the user.
